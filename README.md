# Портфолио — Бекжан Кубатбеков (Бека)

Frontend-разработчик, Бишкек. Сайт на React + Vite, шесть страниц: Главная, Обо мне, Навыки, Проекты, Путь, Контакты.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Своё фото

Положи файл `photo.jpg` в папку `public/` (пропорции 4:5 подходят лучше всего). Пока файла нет, на странице «Обо мне» показывается монограмма BK.

## Где менять тексты

- Контакты, проекты, ссылки — `src/data.js`
- Тексты страниц — `src/pages/`
- Цвета и шрифты — переменные в начале `src/styles.css`

## Деплой

Репозиторий готов к Vercel: framework Vite, команда `npm run build`, папка `dist`. Файл `vercel.json` уже настроен для работы маршрутов.

## Гостевой чат на странице «Контакты»

Чат работает через Supabase. Чтобы он стал общим для всех посетителей:

1. В Supabase откройте SQL Editor и выполните файл `supabase/chat.sql` (создаёт таблицу `portfolio_messages` с правилами доступа).
2. Скопируйте `.env.example` в `.env` и впишите `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (Project Settings, API).
3. На Vercel добавьте те же две переменные в Settings, Environment Variables и сделайте Redeploy.

Без этих переменных чат работает в демо-режиме: сообщения сохраняются только в браузере посетителя.
Чтобы ответить от своего имени, добавьте строку в таблицу в Table Editor с `is_owner = true`.
